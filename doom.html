SAME-STATE POLICY IMPROVEMENT

Counterfactual simulator probe

idle

Training-only search: snapshot the exact environment state, try every typed action for the same number of deterministic engine tics, restore the state, and compare measured causal returns. Probing never changes model weights. Fitting is a separate explicit step and uses a conservative prior-regularized target.

Requires the project-owned runtime with exact snapshots/tic stepping and a prepared fast policy.
